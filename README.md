# 🎓 GradXchange — UNIMAS Marketplace Web Application

GradXchange is a **marketplace web application** designed for **UNIMAS students** to buy, sell, or exchange used items and promote student-run services within the university community.  
It helps graduating students easily sell their belongings before moving out, while also encouraging student entrepreneurship and sustainability.

🌐 **Live Demo:** [https://gradx.store](https://gradx.store) -- (The domain is expired)

---

## 🚀 Overview

### 🎯 Objectives
- Develop a **dedicated online marketplace** for UNIMAS students.  
- Support the **sale of used items** and **student business promotions**.  
- Create a **simple, user-friendly, and secure** web platform.

### 💡 Problem Statement
- Graduating students often struggle to sell their belongings before leaving campus.  
- Finding affordable used items nearby can be difficult.  
- Students have no central space to advertise their small businesses.  
- There’s no existing UNIMAS-specific marketplace for these needs.

---

## 🧠 Features

### 👤 User Features
- ✅ Sign Up, Login, and Reset Password  
- 🔍 Search items or services with advanced filters (price, date, tags, seller)  
- 📦 Add, edit, and manage your own listings  
- 💬 Chat system for real-time communication between users  
- ⭐ Leave feedback on items or services  
- 🧾 View other users’ profiles  
- 🔔 Receive notifications for messages and admin updates  
- 🔓 Login via Google or GitHub (OAuth integration)

### 🛠 Admin Features
- 🧮 Dashboard overview of all listings  
- 🕵️ Approve or reject new item/service posts  
- 📊 Track pending, approved, and sold listings  
- ⚙️ Manage item availability (mark as sold/available)  
- 📢 Send notifications for updates or new messages
